# 剪气口 / 挑 Take 粗剪提示词

全文照录自原作者文章版教程，作者注明「文中的提示词都可以直接复制」。

> 原文出自「大师的AI小灶」视频《全网最深度的 AI 剪辑教程》 https://x.com/dashiAIxz/status/2122492466490433678 及文章版 https://x.com/dashiAIxz/status/2124087160907403401 ，版权归原作者。

```
【流程】先出只有人物口播的粗剪视频（60 帧），确认后再导剪映工程。工程使用整条素材加入出点引用，片段可拖回；调色与粗剪共用同一张参数表。
【依据】以脚本为准判断漏说、多说和重复；脚本里本来就重复的内容不算重复。脚本有但没录的句子列入交付说明。
【留白与停顿】开口和说完按实测的有声起音、收音计算，不按转写时间。
- 开口前留 0.15 秒，说完后留 0.2 秒。
- 0.35 秒以内的自然停顿保留。
- 超过 0.35 秒的停顿：句内犹豫缩到约 0.4 秒；逗号 0.35～0.45 秒；句号 0.55 秒；换段 0.7 秒。
- 剪掉口癖后的句内拼接处只留 0.04 秒。
- 切点保留尾音余韵，但吸气、咳嗽等杂音不因此保留；句间呼吸静音在整片环节处理，不改变节奏。
【重复与重说】同一段内容录了两遍及以上时只留一遍，其余从时间线剔除。说一半重来的半截也要剔除，只留说完整的那次。句内超过 0.35 秒的停顿前后要单独转写，且不带提示词，防止重说被转写吞掉。
【挑 Take】按整句块比较，不按短停顿切开比较。
1. 准确且画面可用：无口误、卡壳、吞音、颠倒词序；人物景别和位置一致；开口时已坐稳，说完前没有起身。
2. 语调饱满、重音准确、情绪有感染力。差距不明显时列出候选，由人工选择。
3. 前后气口连贯。
4. 条件相同时，优先选能整段使用的一遍；仍分不出时用后录的一遍。
【跨 Take 拼接】整段能用同一遍就不拼。确实需要拼接时：
- 只在实测有静音的逗号、句号处拼接，不在词中间或气流未断处切。
- 切点留白按【留白与停顿】执行。
- 人物姿势或位置差异明显时不拼。
- 每处拼接都列入交付说明。
【衔接】口播片段之间一律硬切。
【声音】音频只做剪辑必需的操作，不额外加压缩、EQ、降噪或去混响。
【无法解决的瑕疵】所有版本都有瑕疵且拼接无法解决，或只录了一遍且有瑕疵时，时间线放瑕疵最轻的一遍。脚本有但没录的句子，在对应位置标明。粗剪交付说明列出时间码和问题。
【交付】附上每段使用的 Take 及原因、拼接位置、语速和需复查清单。
```
